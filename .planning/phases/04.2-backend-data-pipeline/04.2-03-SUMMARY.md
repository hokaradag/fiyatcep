## Decisions Made

- `init_db()` is called before `scheduler.start()` inside the lifespan — prevents `OperationalError: no such table` if the scheduler's misfire grace fires a job before DB tables exist (Pitfall 4 from research)
- `run_scrape_cycle` imported inside `lifespan` function (not at module top) — avoids circular import: `main.py` imports `admin.py` which would import `runner.py` which imports `database.py` which imports `main.py` modules
- Integration tests patch `app.main.init_db` and `app.main.scheduler` — isolates endpoint behavior from infrastructure side effects in CI environments without a real DB file
- `write_scrape_log` called with the same `error_entry` dict that gets appended to `results` — single source of truth for error log structure
