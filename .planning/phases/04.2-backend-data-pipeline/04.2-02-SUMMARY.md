## Decisions Made

- Migros endpoint confirmed as `GET /rest/products/search?q={keyword}&sayfa={page}&boyut=48` — no CAPTCHA, JSON accessible with standard UA + Cloudflare cookie from homepage
- Prices are in kurus (integer, e.g. 6995 = 69.95 TL) — confirmed from API response
- Brand field is a dict `{"name": "Torku", "id": 434}` — scraper extracts `brand.get("name")`
- 3 keywords x 2 pages = ~120-180 unique products: sufficient for demo price history data
- run_scrape_cycle() uses SessionLocal() per-scraper for isolation; tests use db_session fixture directly to avoid multi-session complexity in test environment

## Deviations from Plan

None - plan executed exactly as written. Endpoint discovery succeeded without needing the `__NEXT_DATA__` fallback.

## Issues Encountered

- Endpoint required `q=` search term to return products (bare search returns empty `storeProductInfos: []`). Resolved by using keyword-based searches (sut, ekmek, yag) instead of category slug approach.
- Windows terminal Unicode encoding blocked initial JSON inspection (`cp1252` codec error). Resolved by adding `sys.stdout.reconfigure(encoding='utf-8')` in probe scripts.
