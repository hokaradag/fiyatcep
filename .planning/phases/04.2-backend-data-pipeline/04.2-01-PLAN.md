    **backend/scraper/base.py** — per D-06, Research Pattern 3:

    Create `normalize_name(name: str) -> str` function:
    ```python
    import re

    _TR_TABLE = str.maketrans("ğşıöüçĞŞİÖÜÇ", "gsioucGSIOUC")

    def normalize_name(name: str) -> str:
        text = name.translate(_TR_TABLE).lower().strip()
        return re.sub(r"\s+", " ", text)
    ```
    Key: `str.maketrans` handles BOTH upper and lowercase Turkish chars in one pass. The translate happens BEFORE `.lower()` so that İ->I->i and ı->i both work correctly (per Phase 01 decision about uppercase Turkish replacements before toLowerCase).

    Create `upsert_product(db: Session, name: str, brand: str, market_id: str, price: float, is_discounted: bool) -> str` function:
    - Computes `norm = normalize_name(name)`
    - Queries `db.query(Product).filter_by(normalized_name=norm, brand=brand).first()`
    - If not found: creates new `Product(id=str(uuid4()), name=name, brand=brand, normalized_name=norm, created_at=utc_now_str())` and adds to session
    - If found: uses existing product.id
    - Then queries `db.query(MarketProduct).filter_by(product_id=product_id, market_id=market_id).first()`
    - If MarketProduct not found: creates new `MarketProduct(id=str(uuid4()), product_id=product_id, market_id=market_id, current_price=price, is_discounted=1 if is_discounted else 0, last_scraped_at=utc_now_str())`
    - If MarketProduct found: updates `current_price`, `is_discounted`, `last_scraped_at`
    - Flushes session (does NOT commit — caller commits the batch)
    - Returns `market_product.id` (this is Flutter's ProductItem.id per D-02)

    Create `utc_now_str() -> str` helper:
    ```python
    from datetime import datetime, timezone
    def utc_now_str() -> str:
        return datetime.now(timezone.utc).strftime("%Y-%m-%dT%H:%M:%S.000Z")
    ```
    Per Pitfall 6: NEVER use `datetime.utcnow()` (deprecated). Always `datetime.now(timezone.utc)`.

    Create abstract `BaseScraper` class:
    ```python
    from abc import ABC, abstractmethod
    class BaseScraper(ABC):
        @abstractmethod
        def scrape(self, db) -> dict:
            """Returns scrape log dict with keys: market, products_found, products_inserted, products_updated, prices_inserted, errors, duration_ms"""
            pass
    ```
