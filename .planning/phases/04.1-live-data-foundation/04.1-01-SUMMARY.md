## Decisions Made

- **Dedicated discounts table** (not a view): Discounts have own lifecycle fields (valid_until, old_price, new_price, note, is_active) not derivable from price_history. A view approach would require complex logic to infer old_price and expiry from scrape artifacts.
- **Pagination params included but v1-optional**: `limit` and `offset` added to list endpoint specs so Phase 04.2 can implement them later without a contract revision. v1 may ignore.
- **activeDiscountCount as denormalized column**: Live COUNT query at read time adds latency; with daily scraping cadence, denormalized counter updated per cycle is acceptable for v1.
