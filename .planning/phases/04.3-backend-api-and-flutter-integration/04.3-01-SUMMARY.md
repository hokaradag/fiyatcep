# Phase 04.3 Plan 01: Backend API Routes Summary

FastAPI REST API implementing all 11 route variants (products, markets, discounts) per API-CONTRACT.md, with CORS middleware, global error handler, and 12 passing pytest integration tests.

## What Was Built

### Task 1: Products, Markets, Discounts Routers + main.py

Three router files implementing all 11 API-CONTRACT.md route variants:

**backend/app/routers/products.py** (4 routes):
- `GET /api/v1/products` — list all market_products with priceHistory, optional `?marketId` filter
- `GET /api/v1/products/search` — search by name/brand (case-insensitive LIKE), returns matching market_products
- `GET /api/v1/products/{id}/prices` — cross-market prices resolving canonical product_id from market_products.id
- `GET /api/v1/products/{id}` — single product by market_products.id with priceHistory

**backend/app/routers/markets.py** (3 routes):
- `GET /api/v1/markets` — all 7 markets with camelCase fields and bool conversion
- `GET /api/v1/markets/search` — search by market name (case-insensitive)
- `GET /api/v1/markets/{id}` — single market by slug, 404 if not found

**backend/app/routers/discounts.py** (2 routes):
- `GET /api/v1/discounts` — active discounts (is_active=1) with JOIN fields, optional `?marketId`
- `GET /api/v1/discounts/search` — search active discounts by product name

**backend/app/main.py updates**:
- CORS middleware: `allow_origins=["*"]` for Flutter development
- Router registration: products, markets, discounts registered after admin
- Global exception handler returning locked `{error: {message, code}}` envelope

All responses use camelCase field names (marketId, isDiscounted, priceHistory, branchCount, etc.) per API-CONTRACT.md Notes §2.

### Task 2: Pytest Integration Tests

**backend/tests/conftest.py additions**:
- `test_client` fixture: TestClient with DB session overridden via `app.dependency_overrides[get_db]`, lifespan infrastructure patched
- `seed_test_data` fixture: inserts product p1 (Aycicek Yagi 1L / Yudum), market_product mp-migros-001 (Migros, is_discounted=1), 2 price_history rows, 1 active discount

**backend/tests/test_api_routes.py** (12 tests):
1. `test_get_products` — shape check including priceHistory list
2. `test_get_products_by_market` — marketId filter + empty result for unknown market
3. `test_search_products` — q= search + empty q returns []
4. `test_get_product_by_id` — id lookup + 404 for nonexistent
5. `test_get_product_prices` — cross-market prices + 404 for nonexistent
6. `test_get_markets` — 7 markets count + bool type assertion for supportsOnlineOrder/hasLoyaltyProgram
7. `test_get_market_by_id` — id lookup + 404
8. `test_search_markets` — name search + empty q returns []

10. `test_get_discounts_by_market` — marketId filter + empty for unknown market
11. `test_search_discounts` — product name search + empty q returns []
12. `test_error_envelope_format` — 404 response has `error.message` + `error.code`
