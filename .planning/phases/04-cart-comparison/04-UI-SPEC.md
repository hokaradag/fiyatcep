## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge inner padding, row micro-spacing |
| sm | 8px | Between label and sublabel, chip internal spacing |
| md | 16px | Card internal padding, default section spacing |
| lg | 24px | Between major sections on a page |
| xl | 32px | Bottom safe-area padding, large section breaks |
| 2xl | 48px | Not used in this phase |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Touch targets for all tappable rows: minimum 48px height (Flutter ListTile default satisfies this)
- AppBar badge: 16px minimum diameter, positioned at (-4, -4) offset from icon
- Card border radius: 16dp (consistent with existing cards in phases 1-3)
- Snackbar duration: 3 seconds (longer than favorites 1s to allow "Sepete Git" action tap)

## Color

Flutter Material colors — no custom hex palette. Use semantic color roles from existing codebase.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `Colors.white` / `Theme.of(context).scaffoldBackgroundColor` | Page background, card surfaces |
| Secondary (30%) | `Colors.grey.shade100` / `Colors.grey.shade200` | Cart product list background, expanded card row backgrounds, disabled state surfaces |
| Accent (10%) | `Colors.green` / `Colors.green.shade100` | Reserved for specific elements listed below |
| Destructive | `Colors.red` / `Colors.red.shade100` | "Sepetten Çıkar" button icon tint, remove confirmation snackbar |

**Accent (`Colors.green`) is reserved for:**
1. "En Uygun" badge background (`Colors.green.shade100`) and text (`Colors.green`)
2. Cheapest market total price text
3. Match fraction when full match (all N/N products found)
4. "Sepete Ekle" button icon tint (consistent with favorites button which uses red/favorite icon)
5. Cart AppBar icon when cart has items

**Market brand colors** (`marketBrands[marketId].primaryColor`): used only in the market logo container background and the brand banner strip — same as Phase 3 pattern. Do NOT use brand colors as general UI accent.

**Partial match indicator:** `Colors.orange` for the asterisk footnote text and partial match fraction (fewer than N/N). This follows the existing orange usage in market_detail_header_widget.dart line 220.

## Component Inventory

New components to implement for this phase:

### 1. CartAppBarIcon (widget)
- Location: `lib/features/cart/widgets/cart_app_bar_icon.dart`
- Pattern: `IconButton(icon: Icon(Icons.shopping_cart_outlined))` wrapped in a `Stack` with a positioned badge
- Badge: `CircleAvatar(radius: 8, backgroundColor: Colors.red, child: Text('N', style: TextStyle(fontSize: 10, color: Colors.white)))`
- Visibility rule: icon always rendered; badge only shown when `cartCount > 0` (Claude's discretion from D-02, resolved to: always-visible icon, badge conditionally shown)
- Used in: `ProductsPage` AppBar actions, `ProductDetailPage` AppBar actions

### 2. CartProductListSection (widget)
- Location: `lib/features/cart/widgets/cart_product_list_section.dart`
- Renders the reviewable cart at the top of CartComparisonPage (D-09)
- Each row: `ListTile` with product name (14sp bold) + brand (12sp muted) + trailing `IconButton(icon: Icon(Icons.remove_circle_outline, color: Colors.red))` to remove item
- Section header: "Sepetim" (20sp bold) + item count "(N ürün)" in 14sp muted inline
- Empty state: not reachable from CartComparisonPage (page only accessible with items)
- Remove interaction: tapping remove icon calls `cartNotifier.remove(product)` — no confirmation dialog (non-destructive, product can be re-added)

### 3. CartMarketComparisonCard (widget)
- Location: `lib/features/cart/widgets/cart_market_comparison_card.dart`
- Follows `Card(elevation: 2, shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(16)))` pattern
- Collapsed state (default): market logo (56×56 white container, borderRadius 12, brand color icon fallback) + market name (17sp bold) + match fraction label (12sp) + total price (20sp bold, green if cheapest, black87 otherwise) + "En Uygun" badge if cheapest + chevron icon
- Expanded state: all collapsed content + `AnimatedCrossFade` or simple `Column` reveal of matched products (green checkmark + product name + price) and unmatched products (red X icon + product name + "bulunamadı" in 12sp muted)
- Partial match footnote: shown below total price as "* N ürün bu markette bulunamadı" in 12sp `Colors.orange`
- "En Uygun" badge: same visual as existing badge in product_price_section.dart (green.shade100 background, green text, borderRadius 20, horizontal 10 / vertical 4 padding)

### 4. CartComparisonPage (page)
- Location: `lib/features/cart/cart_comparison_page.dart`
- AppBar: "Sepet Karşılaştırması" title + optional "Sepeti Temizle" text button in actions (shows only when cart has items)
- Body: `SingleChildScrollView` > `Column` with:
  1. `CartProductListSection` (padded 16dp)
  2. `SizedBox(height: 24)`
  3. Section header "Market Karşılaştırması" (20sp bold) padded 16dp
  4. `SizedBox(height: 12)`
  5. `ListView.builder` (shrinkWrap, NeverScrollableScrollPhysics) of `CartMarketComparisonCard`, bottom margin 12dp per card, horizontal padding 16dp
- Loading state: `Center(child: CircularProgressIndicator())`
- Error state: standard error pattern (Icons.error_outline 48px red + error text + "Tekrar Dene" ElevatedButton.icon)

### 5. CartNotifier (provider, not a widget but defined here for executor clarity)
- Location: `lib/features/cart/presentation/providers/cart_notifier.dart`
- Mirrors `FavoritesNotifier` exactly — `AsyncNotifier<List<ProductItem>>`
- SharedPreferences key: `'cart_products'`
- Methods: `add(ProductItem)`, `remove(ProductItem)`, `clear()`
- Provider: `cartNotifierProvider`

## Interaction Contracts

### Add to cart (ProductDetailPage)
- Button placed below "Favorilere Ekle" / "Favorilerden Çıkar" button
- `SizedBox(height: 12)` between the two buttons
- Button copy: "Sepete Ekle" (not in cart) / "Sepetten Çıkar" (in cart)
- Button icon: `Icons.shopping_cart_outlined` (not in cart) / `Icons.remove_shopping_cart` (in cart)
- On "Sepete Ekle" tap: add product, show snackbar "Ürün sepete eklendi" with action "Sepete Git" (navigates to CartComparisonPage)
- On "Sepetten Çıkar" tap: remove product, show snackbar "Ürün sepetten çıkarıldı" (no action button, 2s duration)
- Snackbar for add: `duration: Duration(seconds: 3)` — longer to allow "Sepete Git" tap
- Snackbar for remove: `duration: Duration(seconds: 2)`

### AppBar cart icon navigation
- Always rendered; badge visible only when `cartCount > 0`
- Tapping navigates to CartComparisonPage via `Navigator.push`

### Expandable market card
- Entire card is tappable to expand/collapse
- Expansion state is local widget state (`StatefulWidget` or `bool` in `ConsumerStatefulWidget`)
- No animation requirement — simple `if (isExpanded)` conditional render is acceptable
- Expanded section shows a `Divider` at top, then product rows

### "Sepeti Temizle" action
- Location: CartComparisonPage AppBar trailing action
- Visibility: shown only when cart has at least one item
- Interaction: tapping shows `showDialog` with title "Sepeti Temizle?", body "Tüm ürünler sepetten çıkarılacak.", actions: "İptal" (dismiss) + "Temizle" (calls `cartNotifier.clear()`, pops dialog, Navigator.pop back to previous page)
- This is the only destructive action requiring a confirmation dialog in this phase
