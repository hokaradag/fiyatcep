## Spacing Scale

Declared values (multiples of 4 only). The existing codebase uses informal spacing; this spec normalizes it to an 8-point scale for Phase 3 additions.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps within chips, between badge elements |
| sm | 8px | Vertical rhythm between minor elements (badge rows, small SizedBox separators) |
| md | 16px | Default card internal padding, horizontal screen padding |
| lg | 24px | Section breaks between ProductInfoSection / ProductPriceSection / chart section |
| xl | 32px | Not used in Phase 3 new widgets |
| 2xl | 48px | Not used in Phase 3 new widgets |
| 3xl | 64px | Not used in Phase 3 new widgets |

Exceptions:
- Touch target for time-range selector tabs: minimum 44px height (accessibility minimum for tappable areas on iOS/Android)
- Chart area minimum height: 200px (sufficient to show line trajectory without truncation)
- Banner image height in MarketDetailHeaderWidget: 120px (fixed, full-width, covers the top of the Card before the info content)
- Logo container within banner: 56x56px, centered vertically over the bottom edge of the banner (overlapping by 28px)

**Source:** Existing code uses 14/16/20/28px SizedBox values loosely. New Phase 3 widgets align to 8-point grid.

## Typography

All sizes in logical pixels (Flutter dp). No custom fonts — system default.

**4-size scale (fixed — do not add sizes outside this table):**

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px | 400 (normal) | 1.5 | Price diff label (`+X.XX ₺`), chart tooltip date line, empty-state body text, description text |
| Label | 16px | 400 (normal) | 1.45 | Market name in price rows, secondary info text in header, price values in ProductPriceSection (existing code uses 16–18px range; map to 16px Label tier for new additions) |
| Heading | 20px | 700 (bold) | 1.2 | Section headings ("Marketlere Göre Fiyatlar", "Fiyat Geçmişi") |
| Display | 24px | 700 (bold) | 1.2 | Market name in MarketDetailHeaderWidget (already established) |

**Mapping of existing code to this scale:**
- Existing price values in ProductPriceSection (17–18px bold in current code): map to Label 16px at weight 700 for any new price value text added in this phase. Existing lines are preserved as-is without a size change; no new out-of-scale sizes are introduced.
- Price diff label (`+X.XX ₺`): Body 14px / weight 400 / `Colors.grey.shade600` — visual distinction via muted color, not smaller size.
- Chart tooltip date (`"dd MMM"`): Body 14px / weight 400 / `Colors.grey.shade600` — same tier as other secondary text.

**Font weights in use: exactly 2 — 400 (normal) and 700 (bold). No other weights.**

**Source:** Existing widget code: market_detail_header_widget.dart line 58 (24px bold), product_price_section.dart line 53 (17px bold), line 64 (18px bold), product_detail_page.dart line 40 (20px bold), line 45 (15px/1.5).

## Color

Flutter Material colors used throughout. No hex tokens — reference Material color constants.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `Colors.white` / `Theme.of(context).scaffoldBackgroundColor` | Page background, Scaffold background |
| Secondary (30%) | `Colors.grey.shade50` to `Colors.grey.shade200` | Card surfaces (elevation 1-2), stats card, info chips background |
| Accent (10%) | `Colors.green` (shade 600 default) | See reserved-for list below |
| Destructive | `Colors.red` (shade 600 default) | Error icon, "İndirimli" badge, error state text |

**Accent (`Colors.green`) reserved for:**
1. "En Uygun" badge background (`Colors.green.shade100`) and text
2. Cheapest market price value text
3. Cheapest market store icon container background
4. Statistics card "Listelenen Ürün" count text (already established)
5. fl_chart line stroke color for the price history chart line
6. Chart tooltip price text

**Additional semantic colors (not accent, not destructive):**
- `Colors.orange` — "Aktif İndirim" stat count (already established, preserve)
- `Colors.blue` — branch count info chip (already established, preserve)

- `Colors.purple` — loyalty program chip (already established, preserve)

## Visual Focal Points

**Primary focal point:** The cheapest-market price row (green styling + "En Uygun" badge) in ProductPriceSection. This is the single most decision-relevant element on the product detail page — green accent color, bold price text, and the badge combine to direct attention immediately.

**Secondary focal point:** The "Fiyat Geçmişi" chart section heading and the line chart below it. The chart occupies the most vertical space of any single element on the page (200px minimum) and provides context for the price comparison above it.

## Component Inventory

### New: ProductPriceHistorySection

File: `lib/features/products/widgets/product_price_history_section.dart`

**Structure:**
```
Column
  ├── Text "Fiyat Geçmişi"  [Heading 20px bold]
  ├── SizedBox(height: 16)
  ├── [Empty state OR chart]
  │    EMPTY: Text "Fiyat geçmişi henüz mevcut değil"  [Body 14px, grey.shade600]
  │    CHART:
  │      ├── _TimeRangeSelector  (SegmentedButton or custom tab row, height 44px)
  │      │     tabs: 1H | 1A | 3A | 1Y
  │      │     default selected: 1A
  │      │     disabled tabs: grey, non-tappable when data insufficient
  │      └── SizedBox(height: 200px minimum)
  │            └── LineChart (fl_chart)
  │                  line color: Colors.green
  │                  dot radius: 4px (visible dots at each data point)
  │                  stroke width: 2px
  │                  grid lines: horizontal only, Colors.grey.shade200, dashed
  │                  touch: LineTouchData enabled — tooltip on press
  │                  tooltip format: "XX.XX ₺" (primary line, 14px bold green)
  │                            + "dd MMM" (secondary line, 14px, grey.shade600)
  │                  Y-axis: show min/max prices only (2 labels)
  │                  X-axis: show first and last date labels only
```

**Data filtering by time range:**
- 1H (1 Hafta): filter `priceHistory` to last 7 days
- 1A (1 Ay): filter to last 30 days
- 3A (3 Ay): filter to last 90 days
- 1Y (1 Yıl): filter to last 365 days
- If filtered result has fewer than 2 points: that tab is disabled (grey text, `onTap` is null)

## Interaction Contract

### Time Range Selector (ProductPriceHistorySection)

| State | Visual | Behavior |
|-------|--------|----------|
| Selected tab | Brand green background, white text, weight 700 | No action |
| Unselected tab | `Colors.grey.shade100` background, `Colors.black87` text | Tap → update chart data, update selected state |
| Disabled tab | `Colors.grey.shade200` background, `Colors.grey.shade400` text | No tap response, shows label grayed |

Default selection: 1A tab on widget initialization.

### Chart Tooltip (fl_chart LineTouchData)

| State | Visual |
|-------|--------|
| No touch | No tooltip visible |
| Press/hold on chart | Tooltip bubble appears at nearest data point |
| Tooltip content | Line 1: price value `"XX.XX ₺"` at 14px bold green; Line 2: date `"dd MMM"` at 14px grey.shade600 |
| Release | Tooltip disappears |

### Price Row Layout (ProductPriceSection)

| State | Visual |
|-------|--------|
| Cheapest row | Green icon container, green price text, "En Uygun" green badge |
| Cheapest + discounted | Above + red "İndirimli" badge |
| Non-cheapest row | Grey icon container, black87 price text, grey "+X.XX ₺" diff label at 14px muted |
| Non-cheapest + discounted | Above + red "İndirimli" badge |

### Market Detail Banner

| State | Visual |
|-------|--------|
| Brand found in config (logo + banner) | Full banner image, logo over bottom edge |
| Brand found (logo only, no banner) | Solid primaryColor block + logo |
| Brand found (banner only, no logo) | Banner image + Icons.store fallback icon |
| Brand not in config | grey.shade300 solid + Icons.store grey icon |

## Implementation Notes for Executor

### Asset Strategy
Since real brand logos/banners may not exist at implementation time, the executor should:
1. Create `assets/logos/` and `assets/banners/` directories with `.gitkeep`
2. Register directories in `pubspec.yaml`
3. Set `logoAsset: null` and `bannerAsset: null` for all 7 markets in `market_brand_config.dart` initially — the fallback rendering path (solid color + Icons.store) will activate
4. Assets can be dropped in later without code changes

### fl_chart Integration
- Import: `fl_chart: ^0.69.0` in `pubspec.yaml` dependencies
- Run `flutter pub get` after adding
- Widget: `LineChart(LineChartData(...))` wrapped in `SizedBox(height: 200, child: LineChart(...))`
- Touch data: `LineTouchData(enabled: true, touchTooltipData: LineTouchTooltipData(...))`
